# Pixel Arena

A Free Fire tournament platform built for players and competitive gaming communities.

Pixel Arena allows players to manage their profiles, participate in tournaments, track wins, and compete through a secure Firebase-powered backend.

## Features

- Player authentication
- Secure user profiles
- Tournament management
- Player statistics
- Wins and coins system
- Competitive leaderboard support
- Firebase Firestore database
- Firestore security rules

## Tech Stack

- JavaScript
- Firebase Authentication
- Cloud Firestore
- HTML/CSS
- Firebase Security Rules

## Security

User data is protected using Firebase Authentication and Firestore Security Rules. Players can only access and modify permitted profile information.
